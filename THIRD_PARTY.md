# Sources and third-party resources

The baseline, metric functions and residual refinement architectures were contributed for this course project. Integration preserves their numerical algorithms while adapting imports, paths, output formats, shared manifest validation and evaluation on the original ground truth. The refinement designs include a three-layer residual CNN, a multi-scale encoder/decoder, RGB/depth gated fusion and an HSV-highlight-aware variant. Their architecture is separate from the released Depth Anything V2 model.

- **C3VD:** Bobrow et al., *Colonoscopy 3D video dataset with paired depth from 2D-3D registration*, Medical Image Analysis (2023), [DOI](https://doi.org/10.1016/j.media.2023.102956). Obtain data from the [official release](https://durrlab.github.io/C3VD/). The dataset and derived example images are subject to CC BY-NC-SA 4.0. Data are not distributed through Git.
- **Depth Anything V2:** Yang et al., *Depth Anything V2*, NeurIPS 2024, [paper](https://arxiv.org/abs/2406.09414), [official implementation](https://github.com/DepthAnything/Depth-Anything-V2). The recorded source revision is `a561b849ebae10a6f5ef49e26c83cbbcd36c71bf`. The [upstream license section](https://github.com/DepthAnything/Depth-Anything-V2/blob/a561b849ebae10a6f5ef49e26c83cbbcd36c71bf/README.md#license) identifies the Small model as Apache-2.0; other model sizes have different terms. Preserve upstream license files when obtaining that repository. Its DINOv2-derived components retain their upstream notices. The official source and weights are obtained separately, not vendored here.
- **Relative Small checkpoint:** [official download](https://huggingface.co/depth-anything/Depth-Anything-V2-Small/resolve/main/depth_anything_v2_vits.pth). The experiment's SHA-256 is `715fade13be8f229f8a70cc02066f656f2423a59effd0579197bbf57860e1378`.
- **U-Net:** Ronneberger et al., *U-Net: Convolutional Networks for Biomedical Image Segmentation*, MICCAI 2015, [paper](https://arxiv.org/abs/1505.04597), motivates the multi-scale skip-connected design; this project does not redistribute the original U-Net implementation.

The selected original Highlight C1 seed-123 checkpoint is included at `checkpoints/highlight_c1/seed_123_best.pth`; other returned refinement checkpoints are excluded from Git. Its SHA-256 is `bbc7ff76c5ccb89b6bbd70e05c0510993acb7c73057bc9956cd9e42140c0060a`. This repository does not add a separate release license for the contributed checkpoint. The training entry point can produce new weights, but numerical equivalence to the archived training run has not been established. This notice records attribution and resource-specific terms; it does not grant a new blanket license for contributed code or private artifacts.
